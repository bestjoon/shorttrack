쇼트트랙 선수 정보 데이터를 수집하여 DB로 만들기 위해 아래 작업을 하고자 함.

최대한 많은 선수 데이터를 확보하기 위해 각 대회의 종별+종목별(예:남자중학부 1000M)로 첫 번째 라운드의 참가자 데이터를 기준으로 데이터를 수집하고자 하며, 한 선수 데이터는 그 선수가 참가한 대회/종목/라운드를 선택하든 동일한 데이터가 조회됨. (종별+종목별로 첫번째 라운드가 다를 수 있음. 예를 들어 여자중학부 1000M는 예선부터 실시되지만, 여자초등5~6학년 1000M는 준준결승부터 실시되는 경우도 있음)


1. 아래 빙상연맹 경기결과 검색 페이지에서 대회를 선택. 지금은 "제40회 전국남녀 종별종합 쇼트트랙스피드스케이팅 선수권대회"를 선택.

https://result.sports.or.kr/SK/INF201.do

2. 종별(예:남자중학부)로 세부 종목 중 1000M를 선택(클릭)하여 경기구분(라운드) 중 가장 빠른 라운드(예선-준준결승-준결승-결승B-결승A 순서)를 선택하여 "상세조회" 선택.
   각 종별로 가장 빠른 라운드가 서로 다를 수 있음(예를 들어, 1000M 종목이라 하더라도 남자중학부는 예선부터 시작하지만 여자초등5~6학년은 준준결승부터 시작하는 경우가 있음).
   따라서 데이터가 0건 조회되는 경우에는 그 다음 라운드를 조회하는 로직이 필요함.

3. 경기결과에서 성명을 한 명씩 클릭하면, 해당 선수의 상세 정보가 조회됨. 선수의 최종등록정보는 마스터데이터 성격이며, 대회참가이력은 대회 참가시마다 추가되는 Historical 데이터임.

4. 최대한 많은 데이터를 수집하기 위해서, 위 2~3번 과정을 반복하거나 혹은 데이터를 스크랩하는 파이썬 프로그램을 작성해 줘 (프로그램 작성이 더 유용함). 수집된 데이터는 SQL Lite DB로 저장해 줘.

5. 데이터 수집 프로그램 작성시에는, 향후 다른 대회 때도 사용할 수 있도록 대회,종별,종목,경기구분(라운드) 등은 파라미터로 처리할 수 있도록 프로그램 되어야 함.

단, 이번 종별종합 대회는 모든 선수들이 3종목(500M, 1000M, 1500M)를 전부 출전하지만, 대회에 따라서는 여러 종목 중 선택적으로 참가하는 경우가 있기 때문에, 데이터 수집시에는 종별로 모든 종목 데이터를 다 확인해야 하며, 중복 데이터(선수ID 또는 선수명+소속이 겹치는 경우)는 skip하도록 해야 함. DB에 저장시에도 중복 데이터는 skip하도록 해야 함.
