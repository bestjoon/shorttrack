사용 방법
1. 위 영역에 shorttrack_players.db 파일을 드래그하거나 클릭하여 선택
2. 자동으로 변환이 시작되며 완료 후 다운로드 버튼 클릭
3. 다운로드된 shorttrack_data.json을 viewer.html과 같은 폴더에 저장
4. viewer.html을 열어 데이터 조회
